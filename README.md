one-cat-joke is a tiny program that writes one one-line joke about a cat to a file: the cat writes an obituary for a houseplant, and the last word of the eulogy gives away what really happened to the plant. The line is 84 characters long, short enough to read aloud in one breath.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
